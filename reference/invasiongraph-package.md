# invasiongraph: Community assembly analysis with invasion graphs

Functions for calculating the invasion pathways by which communities
assemble using the principles of Modern Coexistence Theory. The code for
the core functions was written by Sebastian Schreiber and included as a
Supplementary File with Hofbauer & Schreiber (2022; doi:
10.1007/s00285-022-01815-2). This package is intended to enable easier
access to this code.
